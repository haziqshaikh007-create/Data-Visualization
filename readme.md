# 📊 IPL 2022 Data Visualization Capstone Project

This repository showcases my complete journey of learning and applying **data visualization in Python**. Through extensive practice with **Matplotlib**, **Seaborn**, and **Plotly Express**, I explored a wide range of plots — from basic line and bar charts to distributional plots, categorical plots, regression plots, and matrix plots — each studied and implemented in separate practice files. Building on this foundation, I applied my knowledge to a full **capstone project analyzing IPL 2022 data**, where I cleaned, processed, and visualized match statistics to uncover insights into team performance, player contributions, toss decisions, and overall tournament trends. This project represents the culmination of my visualization tutorial: combining hands‑on practice with real‑world data storytelling to produce meaningful charts, comparisons, and insights that highlight the power of Python’s visualization libraries.
